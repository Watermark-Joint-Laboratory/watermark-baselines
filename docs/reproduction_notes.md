# Reproduction Notes

每次正式复现新增一条记录，可按日期和方法拆分文件。

```markdown
## YYYY-MM-DD / METHOD / DATASET

- Operator:
- Reviewer:
- Repository commit:
- Upstream commit:
- Config:
- Model and revision:
- Dataset and revision:
- Seed:
- Hardware:
- Environment:
- Command:
- Result location:
- Paper result:
- Reproduced result:
- Deviations:
- Known issues:
```

结果不一致也应记录。不要只保留“最好的一次”；需要说明失败原因、修复和最终采用的配置。
